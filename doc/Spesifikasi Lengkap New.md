**KEBUTUHAN APLIKASI BERBASIS WEB**

**WORLDWIDE GLOBAL EDUCATION**

Aplikasi berbasis web Worldwide Global Education merupakan sistem terintegrasi untuk mengelola **promosi, penerimaan siswa, pembelajaran offline dan online, ujian, event, administrasi, keuangan, pembayaran, jadwal kelas, serta sistem afiliator**.

Sistem harus bersifat **modern, responsif, scalable, multi-user, multi-cabang, dan terintegrasi antar-modul** sehingga data yang dimasukkan pada satu modul dapat digunakan oleh modul lainnya tanpa perlu input berulang.

**MODUL UTAMA SISTEM**

Sistem terdiri dari **10 modul utama**:

1. Website Company Profile
2. Sistem Penerimaan Siswa Baru / PPDB
3. Learning Management System (LMS)
4. Sistem Ujian Online (CBT)
5. Sistem Event Online Berbayar
6. Sistem Jadwal & Ruangan Kelas Offline
7. Sistem Afiliator / Referral
8. Sistem E-Sertifikat Otomatis
9. Sistem Administrasi & Keuangan
10. Sistem Pembayaran

Selain itu terdapat **Dashboard Management & Reporting** yang mengintegrasikan seluruh modul.

**7\. SISTEM AFILIATOR / REFERRAL**

Sistem afiliator digunakan untuk memungkinkan siswa, alumni, tutor, atau pihak tertentu mempromosikan program Worldwide dan mendapatkan komisi dari pendaftaran yang berhasil.

**A. Jenis Afiliator**

Admin dapat menentukan kategori:

- Siswa
- Alumni
- Tutor
- Orang tua
- Partner
- Umum

**B. Akun Afiliator**

Setiap afiliator memiliki:

- ID afiliator
- Nama
- Nomor WhatsApp
- Email
- Kode referral
- Link referral
- Total referral
- Total komisi
- Komisi dibayar
- Komisi belum dibayar

Contoh kode:

**WW-JUNAIDI01**

**C. Link Referral**

Sistem menghasilkan link khusus.

Contoh:

website.com/daftar?ref=WW-JUNAIDI01

Ketika calon siswa mendaftar melalui link tersebut, sistem otomatis mencatat afiliatornya.

**D. Kode Referral**

Selain link, calon siswa dapat memasukkan:

**Kode Referral: WW-JUNAIDI01**

**E. Tracking Referral**

Sistem mencatat:

- Siapa afiliatornya
- Calon siswa yang direferensikan
- Tanggal pendaftaran
- Program yang dipilih
- Nilai transaksi
- Status pendaftaran
- Status pembayaran
- Status komisi

**F. Aturan Komisi**

Admin dapat menentukan metode komisi:

**Komisi Nominal**

Contoh:

Setiap siswa baru yang berhasil bergabung:

**Rp20.000/siswa**

**Komisi Persentase**

Contoh:

**5% dari pembayaran tertentu**

**Komisi Berdasarkan Program**

Contoh:

- Program A → Rp20.000
- Program B → Rp30.000
- Program C → Rp50.000

**Komisi Bertingkat**

Jika diperlukan, sistem dapat mendukung:

- Komisi pendaftaran
- Komisi pembayaran pertama
- Komisi pembayaran berikutnya

Aturan komisi harus dapat dikonfigurasi oleh admin.

**G. Syarat Komisi**

Komisi tidak langsung dianggap valid ketika formulir diisi.

Status dapat berupa:

1. Pending
2. Pendaftaran terverifikasi
3. Pembayaran terverifikasi
4. Komisi valid
5. Siap dicairkan
6. Dicairkan
7. Dibatalkan

Hal ini mencegah komisi diberikan untuk pendaftaran palsu atau pembayaran yang belum valid.

**H. Dashboard Afiliator**

Afiliator dapat melihat:

- Link referral
- Kode referral
- Jumlah klik
- Jumlah calon siswa
- Jumlah pendaftar
- Jumlah siswa berhasil
- Total komisi
- Komisi pending
- Komisi tersedia
- Komisi yang sudah dibayarkan
- Riwayat pencairan

**I. Pencairan Komisi**

Afiliator dapat mengajukan pencairan.

Data:

- Nominal
- Bank/e-wallet
- Nomor rekening
- Nama rekening
- Bukti pembayaran
- Status pencairan

Admin melakukan verifikasi.

**J. Anti Fraud**

Sistem sebaiknya memiliki perlindungan terhadap:

- Referral diri sendiri
- Duplikasi akun
- Pendaftaran palsu
- Pembayaran palsu
- Manipulasi referral
- Komisi ganda

Admin dapat membatalkan referral/komisi yang tidak valid.

**26\. TUJUAN AKHIR SISTEM**

Sistem Worldwide Global Education diharapkan menjadi **Integrated Education Management System** yang menggabungkan:

**Website + PPDB + CRM Siswa + Akademik + Bimbel Offline + LMS + CBT + Event + Jadwal + Ruangan + Absensi + Pembayaran + Keuangan + Afiliator + Sertifikat + Reporting**

dalam satu platform.

Dengan konsep tersebut, sistem bukan hanya menjadi LMS atau aplikasi bimbel, tetapi menjadi **sistem manajemen lembaga pendidikan yang dapat digunakan untuk mengelola Worldwide Global Education dari proses mendapatkan calon siswa sampai siswa selesai mengikuti program.**

Sistem juga harus dirancang **scalable**, sehingga di masa depan dapat ditambahkan:

- Aplikasi Android/iOS
- WhatsApp Bot
- AI Tutor

- AI Analisis Nilai
- CRM
- Payroll Tutor

- POS/Kasir
- Sistem membership

- Integrasi payment gateway lainnya
